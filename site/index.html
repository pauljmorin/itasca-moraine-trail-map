Data sources

  • Trail line: North Country Trail Association, on behalf of the National Park Service (official public depiction)
  • Parcels: Minnesota Geospatial Commons (MnGeo) compiled county parcels; Hubbard County open data (Hubbard is not in the state compilation). The parcels layer is off when the map opens; its data loads only when you switch it on.
  • Non-road access: Minnesota DNR — state park trails & roads, OHV trails, state trails, snowmobile trails, hunter walking trails
  • Roads: Minnesota DNR / MnDOT road centerlines, plus Minnesota DNR state forest roads
  • Roads and access lines are shown within a corridor of the trail; faded ends continue beyond it.
  • Mile markers: North Country Trail Association Minnesota half-mile points (the state mileage index)
  • Mile markers show the state (NCTA) reckoning; the chapter tracker's mile figures differ by roughly 46–48 miles and are labelled as tracker miles where shown.
  • Sections & gaps: the chapter's adoption tracker and segment boundary points, joined onto the official line
  • Waypoints (parking, camping, shelters, water, points of interest) and the Find index: North Country Trail Association public point data, plus the layers above
  • Base map — Topo (default): OpenTopoMap (CC-BY-SA); map data © OpenStreetMap contributors, SRTM
  • Base map — Streets: © OpenStreetMap contributors
  • Base maps — USGS Topo 1:24k and Aerial (NAIP imagery): USGS The National Map
  • Base map — Hillshade: Minnesota Geospatial Image Service (MnGeo / Minnesota DNR), derived from 1 m LiDAR. The terrain view — the moraine itself; recommended for reading the land.
  • Base map — Aerial: Esri World Imagery
  • Additional candidate bases (added Nov 10, 2026 for review; some will be removed): USGS ImageryTopo; Esri World Topographic and National Geographic; CARTO Voyager and Positron; CyclOSM; Esri World Hillshade; OSM Humanitarian. Stamen Terrain (Stadia) and Thunderforest Outdoors are listed but need a free API key before their tiles load.

Adopted sections show placeholder adopter names (Test adopter 1, 2, …) — the chapter's real adopter names are kept in its working files and never appear on this map. Parcel owner names and addresses, as published in the county parcel records (public record), appear in parcel popups when the parcels layer is switched on.
