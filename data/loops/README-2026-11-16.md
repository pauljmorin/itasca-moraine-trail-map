# Waboose Lake Loop + Lake Erin Loop + Nelson Lake Loop — geometry found (2026-11-16)

Both loops were missing from the map: Waboose is tracker-only (gap-analysis D6,
joined by annotation on the West-14 pin); Lake Erin has maintenance items
(M-007, M-011, M-012) but no line. Nelson Lake Loop was added the same day
(Paul: "on the border between west 9 and 10"). Files staged here, ready to
wire into the viewer as a layer. Waboose + Lake Erin are wired into
site/app.js as "Chapter loops" (Nov 16, code only — not yet deployed);
Nelson Lake is staged here, not yet wired.

## Waboose Lake Loop — `waboose-loop.geojson`

- **Source: OpenStreetMap** (ways 846251459 + 846251460, `highway=footway`,
  `name=Waboose Lake Loop`), fetched 2026-11-16 via api.openstreetmap.org.
  ODbL — the map's data-sources page needs an OpenStreetMap attribution
  line if this goes live.
- **The DNR has no GIS line for it.** Checked the DNR enterprise services
  (enterprise.gisdata.mn.gov): the `trans_*` inventory has state trails,
  state park trails, state forest *roads*, hunter walking, OHV, snowmobile
  and water trails — no state-forest hiking-trail layer. The old
  `arcgis.dnr.state.mn.us/host/.../Minnesota_Trails...` FeatureServer 404s
  entirely. The DNR's only representation is the Paul Bunyan & Badoura
  State Forest map GeoPDF (sft00002_geo.pdf) — a picture, not a line.
  Overpass was unreachable from this VM during the hunt (406/502/connection
  failures on all three mirrors); the OSM API bbox fetch worked instead.
- **Assembled loop: 3.64 mi** (published length 3.9 mi; the gap is the
  trailhead clearing plus the ~100 yd campsite spur, neither mapped as
  tread). Parts: west+north 0.94 mi, south+west 2.34 mi, east side 0.37 mi.
- **East side IS the NCT tread**: OSM way 846251458 ("North Country
  Trail", 224 pts) passes exactly through both loop junctions; the 589 m
  sub-path between them is the shared section. That tread is already drawn
  on the map as the NCT — the loop file carries it as a separate feature
  so the loop can be drawn whole.
- **Caveat: 35 m gap at the trailhead** where the two loop ways end at
  slightly different nodes by the parking area. Left open on purpose — no
  tread invented. At map scale it is invisible; a chapter GPS walk could
  close it exactly.
- **Checks passed**: both ways pass 23–26 m from the known trailhead
  (47.058075, -94.832952); loop length within 7% of published; east-side
  segment stays east (lon -94.822..-94.819).

## Lake Erin Loop — `lake-erin-loop.geojson`

- **Source: USDA Forest Service, National Forest System Trails**
  (TrailNFS_Publish, service EDW_TrailNFSPublish_01, refreshed
  2026-11-15). Trail "LAKE ERIN HIKING", no. 34914, class 3, native
  material, **0.619 GIS miles**, 229 points. Public-domain federal data.
  (Note: this one is Forest Service land, not DNR — Chippewa National
  Forest, 7 mi SE of Walker on Hwy 371; trailhead 47.016017, -94.535922.)
- **Caveat: the line is NOT closed.** It runs from the trailhead around
  the lake and ends at the NCT spur junction on the south side; the
  remaining ~150 m back to the trailhead is the parking-area edge, not
  mapped tread. Drawn as-is it reads as a loop with a small gap at the
  parking lot — same treatment as Waboose.
- **Checks passed**: 0.619 mi matches the published 0.6 mi loop; bbox
  lon -94.53577..-94.53220, lat 47.01440..47.01791, centred on the known
  trailhead; start point 47.01642, -94.53577 sits at the trailhead.

## Nelson Lake Loop — `nelson-lake-loop.geojson`

- **Source: OpenStreetMap** (ways 505705378 + 889604647 + 889604649,
  `name=Nelson Lake Trail`, `highway=footway`; way 508873979, `name=Lake
  Twentyone Trail`, `highway=footway`), fetched 2026-11-16 via
  api.openstreetmap.org. ODbL — the OSM attribution line already added
  for Waboose covers this too.
- **Which Nelson Lake: the one in Paul Bunyan State Forest near Laporte,
  at the West-9 / West-10 segment boundary.** The trail's NCT junction
  (-94.84658, 47.15307) sits 3.2 m from the West-9/West-10 boundary point
  (-94.84655, 47.15305) in the chapter's own stretches file — Paul's
  description pins it exactly. (Three other Nelson Lakes in Minnesota
  were ruled out: Pillager/Cass, Lake Park/Becker, Hines/Beltrami.)
  Trailhead 47.161752, -94.841417 (Gulch Lake Campground, connects
  directly to the NCT).
- **Assembled: 2.26 mi** (published loop 2.4 mi, AllTrails; the gap is
  the campground spur, not mapped as tread). Parts: Nelson Lake Trail
  1.25 mi (three ways), Lake Twentyone Trail 1.01 mi (one way).
- **Caveat: ~140 m gap on the north-east side** between the end of way
  505705378 and the start of way 889604647, across the Gulch Lake
  Campground area; the Lake Twentyone Trail's end sits 47 m from the
  same junction. Left open on purpose — no tread invented. Same
  treatment as Waboose.
- **Checks passed**: junction 3.2 m from the West-9/10 boundary;
  total 2.26 mi within 6% of the published 2.4 mi; the Lake Twentyone
  Trail connects the loop to Lake Twenty-one as the inventory describes.
